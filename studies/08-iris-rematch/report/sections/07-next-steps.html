Next Steps

  1. Run the learning-curve arena where headroom actually exists. This study's central question — does a tabular foundation model earn its keep when data runs out? — was fog-bound here, because the incumbent's error and its own floor scale together on this pair. On a problem where the incumbent's error is many floor units above zero, the same ladder becomes measurable rather than closed. The candidates already in this repository are the motor-insurance frequency and severity studies and the hurricane return-level work.

  2. Give the Gaussian process a bounded kernel and a second chance. Its failure here was a probability-integral pathology on near-separable fits, not a statement about the method. Registering a bounded-kernel variant as a candidate would test whether the pathology is fixable inside the same guard — and the existing crash rows give it a pre-measured target to beat.

  3. Reuse the capture-ratio lane as a general pattern. For any claim of the form "the modern method wins", register the classical-family-adjustment lane first and report the observed capture ratio beside the headline. It costs three extra candidates and it is the difference between "a 2025 model beat a 1936 rule" and "the gain was 98% available by adjusting the 1936 rule". Both sentences can be true of the same numbers; only one of them is worth acting on.

  4. Put the headroom audit in the framework itself. The one table that made this study cheap is currently a study-local script. As a first-class step — run it at the metrology phase, publish it before any challenger — it would save every future study the cost of discovering a closed door from the inside.
