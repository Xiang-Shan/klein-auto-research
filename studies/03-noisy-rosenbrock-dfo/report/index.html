The Question

Every tuner of anything noisy has lived this moment: you change a knob, the number improves, and a small voice asks — improved, or got lucky? This study puts that moment under a microscope with the cleanest possible specimen: minimize the Rosenbrock banana function when every evaluation you request comes back corrupted by Gaussian noise (σ = 0.5), and you may ask for only 200 evaluations. The true surface has a known minimum, f* = 0 at (1, 1) — so unlike real life, we can score every answer against truth.

Three contenders, one fixed budget: single-start Nelder-Mead (the default reflex), the same budget split across random restarts, and SPSA — the stochastic-approximation method literally designed for noisy evaluations. Three research questions were registered with priors before any run: do restarts pay (RQ1)? does SPSA beat them at this budget (RQ2)? does finer restart fragmentation keep paying (RQ3)?

The real subject, though, is the discipline: a measured noise floor instead of a guessed significance bar, a sealed fresh-noise confirmation spent exactly once, every discard and crash kept as evidence — and, as it turned out, the study's biggest finding was made by a gate before the first experiment ran.

The Method

SPSA (Simultaneous Perturbation Stochastic Approximation, Spall 1992) is the unfamiliar method here, so it got the full method-card treatment before any run. The idea in one breath: a finite-difference gradient in d dimensions costs 2d evaluations, but if you nudge all coordinates at once with a random ±1 vector Δ and take just two measurements, the quantity

is a wrong gradient whose wrongness has mean zero — so gradient descent on it still walks downhill, at two evaluations per step regardless of dimension. The catch is the gain sequences and : SPSA's guarantees are asymptotic, and its first steps are only as sane as is matched to your gradient magnitudes. Spall's 1998 implementation paper says exactly how to size it — from the desired magnitude of the first step. Remember that sentence; the journey section shows what happens to a researcher who reads it and then doesn't apply it.

The baselines: Nelder-Mead maintains a simplex of 3 points (in 2-D), reflecting/expanding/contracting by comparing function values — comparisons that noise can silently invert. Random restarts split the same 200 evaluations across k independent starts and keep the best finisher: exploration purchased at the price of per-start depth.

The Data

A synthetic lab's "data" is its generator plus its seed discipline. The generator is fixed: true Rosenbrock plus per evaluation, hard 200-evaluation budget, R = 40 independent repetitions per experiment, each rep scored as true f(answer) − f* — the optimizer never sees the truth it is scored on. The seed contract does the work a train/test split does elsewhere: development block 42–81, four extra floor-measurement blocks, and a sealed final-test block 10042–10081 — pairwise disjoint by construction, proven mechanically by prepare.py.

The DATA gate's clean-room audit then ran its harness-sanity check — and made the study's biggest single discovery before experiment one: plain random search (200 uniform darts, keep the best-looking) scores a mean true gap of 0.397, while single-start Nelder-Mead scores 1.251. The no-information baseline beats the default method 3.2×. A noiseless probe (NM solves the clean function to exactly 0.0 on all 40 starts) proved the harness sane: the noise is the entire problem — it corrupts NM's simplex comparisons until the search stalls wherever the noise first confuses it.

The other Phase-0 ritual: the measured noise floor. The anchor config was rerun on five disjoint seed blocks: means 1.25–2.00, std 0.2848. The keep bar (minimum_delta) was set to 2× that — 0.5695 — and the contract records the whole measurement. One humbling detail: the development block turned out to be the luckiest of the five.

Coding Advice

  1. Measure the floor before judging any delta [C4]. Five reruns of the identical config across seed blocks cost seconds and re-priced every later comparison: the bar became 0.5695, and the development block turned out to be the luckiest of five. A delta below your floor is weather, not climate.
  2. Run the dumb baseline first [C5]. Random search at the same budget would have re-framed this study before it began — and the clean-room audit's chance check is exactly where it surfaced. Budget one ledger row for it next time.
  3. Scale gain sequences from YOUR landscape, not from the paper's example [C6]. Apply Spall 1998's first-step rule to your measured gradient magnitudes; here it prescribes , four orders below the "textbook" 0.1 that diverged.
  4. Register crash predictions on mechanisms [C7]. "It will diverge" and "it will be non-finite" are different claims; only the denominator is structurally guaranteed to die. The ledger now teaches both.
  5. Let the harness keep your losers. E0004's 1e196 and E0005's ZeroDivisionError are this study's most-cited rows — and both resolve to their exact candidate commits because the loop commits before it runs.

"""The only per-candidate mutable surface in a Klein v2 study.

Simulation harness for noisy-Rosenbrock derivative-free optimization: the
CONFIG block below is the 5–15-line experiment surface; objective.py and
optimizers.py are stable study libraries.
"""

from __future__ import annotations

import csv
import os
import statistics
import time
from pathlib import Path

from kleinlib.eval import evaluate_scalar
from objective import (
    DEV_BASE,
    EVAL_BUDGET,
    F_STAR,
    FINAL_BASE,
    N_REPS,
    NoisyBudgetedObjective,
    block,
    rosenbrock,
)
from optimizers import nelder_mead, nm_restarts, spsa

EXPERIMENT_ID = os.environ.get("KLEIN_EXPERIMENT_ID")
TRACK = os.environ.get("KLEIN_TRACK")

# ---- CONFIG: the per-experiment surface (keep diffs 5-15 lines) ----
OPTIMIZER = "nm_restarts"  # nm | nm_restarts | spsa
ADAPTIVE = False          # Nelder-Mead adaptive (Gao-Han) parameters
N_RESTARTS = 4            # nm_restarts: starts sharing the SAME total budget
SPSA_A0 = 0.1             # SPSA gain-sequence scale
SEED_BASE_OVERRIDE = None  # measurement sweeps only; never for frontier runs
# --------------------------------------------------------------------


def run_rep(seed: int) -> float:
    objective = NoisyBudgetedObjective(seed, budget=EVAL_BUDGET)
    x0 = objective.random_start()
    if OPTIMIZER == "nm":
        answer = nelder_mead(objective, x0, EVAL_BUDGET, adaptive=ADAPTIVE)
    elif OPTIMIZER == "nm_restarts":
        answer = nm_restarts(objective, N_RESTARTS, EVAL_BUDGET, adaptive=ADAPTIVE)
    elif OPTIMIZER == "spsa":
        answer = spsa(objective, x0, EVAL_BUDGET, a0=SPSA_A0)
    else:
        raise RuntimeError(f"unknown OPTIMIZER {OPTIMIZER!r}")
    return rosenbrock(answer) - F_STAR  # scored on the TRUE function


def seed_base(evaluation_kind: str) -> int:
    if SEED_BASE_OVERRIDE is not None:
        return int(SEED_BASE_OVERRIDE)
    return FINAL_BASE if evaluation_kind == "final_test" else DEV_BASE


def main() -> None:
    t0 = time.time()
    evaluation_kind = os.environ.get("KLEIN_EVALUATION_KIND")
    missing = [
        name
        for name, value in (
            ("KLEIN_EVALUATION_KIND", evaluation_kind),
            ("KLEIN_EXPERIMENT_ID", EXPERIMENT_ID),
            ("KLEIN_TRACK", TRACK),
        )
        if value is None
    ]
    if missing:
        raise RuntimeError(
            "train.py must be invoked through `klein run-one`; missing "
            + ", ".join(missing)
        )
    if evaluation_kind not in {"development", "final_test"}:
        raise RuntimeError(f"invalid KLEIN_EVALUATION_KIND={evaluation_kind!r}")

    base = seed_base(evaluation_kind)
    gaps = [run_rep(seed) for seed in block(base, N_REPS)]
    mean_gap = statistics.fmean(gaps)

    if OPTIMIZER == "nm" and not ADAPTIVE and base == DEV_BASE:
        reference = Path("data/prepared/reference_cell.csv")
        if reference.is_file():
            with reference.open("r", encoding="utf-8", newline="") as f:
                rows = list(csv.DictReader(f))
            ref_mean = statistics.fmean(float(r["final_gap"]) for r in rows)
            if abs(ref_mean - mean_gap) > 1e-9:
                raise RuntimeError(
                    f"split-identity anchor FAILED: prepared reference mean {ref_mean!r} "
                    f"vs recomputed {mean_gap!r} — seed plumbing drifted, STOP"
                )

    evaluate_scalar(
        mean_gap,
        exp_id=EXPERIMENT_ID,
        metric_name="mean_final_gap",
        metric_goal="lower",
        study_dir=".",
        t0=t0,
        extra={
            "gap_std_across_reps": statistics.stdev(gaps),
            "gap_median": statistics.median(gaps),
            "gap_worst": max(gaps),
            "n_reps": float(N_REPS),
            "wall_seconds": time.time() - t0,
        },
    )


if __name__ == "__main__":
    main()
