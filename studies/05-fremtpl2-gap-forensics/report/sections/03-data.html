The value-pattern gotchas (checked against raw tokens, never dtypes)

Klein's standing war story is that dtype == "object" checks lie under pandas string dtypes, so the audit reads raw CSV tokens with dtype=str, na_filter=False. All 12 columns, by value:

  • VehGas is a two-level string binary — exactly {Regular: 345,877, Diesel: 332,136}. Not Yes/No, not 0/1. This is the exact shape that silently skipped categorical handling in the ancestor campaign. It is listed in pipeline.CATEGORICAL, so OHE picks it up — no dtype-based skip.
  • VehBrand and Region are digits-inside-strings (B12, R24). They must never be coerced to numbers.
  • Density has a real censoring ceiling — 10,515 rows (1.55%) pinned at exactly 27,000, so p99 == max. A genuine ceiling in the source, not a sentinel; never treat it as missing. Skew 4.65 → 0.05 after log1p, which is why the shaped GLM configs log it first.
  • The SENTINEL regex fired twice and both were false positives — the substring 999 inside legitimate IDpol/Density integers, and the letter F as an Area level. Dismissed by inspecting the full value sets.
  • IDpol is a perfect row identifier (678,013 unique, monotone increasing, r = −0.0396 with the target). Structurally excluded — X is built from the 9 modelled columns only.
  • The exposure lower clip silently binds. 1,060 rows sit at exactly repr(1/365.25) — the 19-decimal fingerprint of prepare.py's clip — while the hygiene counter reports 0, because it only counts rows outside (0, 1]. Recorded, not fixed: prep is frozen.
  • The ClaimNb cap at 4 is a no-op here. 0 rows exceed 4 pre-clip; 13 rows sit at the cap. The hub table arrives already capped — the guard is inherited, not applied.
  • Zero missing values, zero whitespace padding, zero mixed-type columns, zero true sentinels.

The dominant caveat: feature-profile twins straddle the split

The 9 modelled features repeat heavily — 528,765 distinct profiles over 678,013 rows. Under the seed-42 split, 31,798 profile groups span train and development, so:

26.54% of development rows (35,985 / 135,603) and 26.37% of sealed-test rows have a feature-identical twin in the train fold.

These are not full-row duplicates — IDpol is unique and Exposure varies, so the mechanized duplicate-row check correctly passes. They are policies with identical rating characteristics. The decision was to record, not fix: deduplicating or switching to a group split would break the 0.454861 / 0.444689 anchors and destroy cross-study comparability.

This is exactly why the study's standing directive is report the GAP, never the levels. Both tracks consume identical contamination, so the GLM↔GBDT difference — the actual estimand — is unbiased by it; what is optimistic is every absolute deviance versus a fresh portfolio. The upside is also bounded: twin rows are claim-poor (1.97% claim-bearing among the dev twins vs 3.68% overall).

The other reason levels lie: the folds are not identically frequent

Exposure-weighted frequency by partition:

train  0.073900          development  0.072375          sealed test  0.074350

A model calibrated on train therefore must over-predict development by 0.073900 / 0.072375 = 1.021 and under-predict the sealed test by 0.073900 / 0.074350 = 0.994 — before any question of model quality. Hold that thought; section 5 shows it explaining an apparent calibration finding almost exactly.

The clean-room leakage audit — and the leak that was already removed

Performed in a fresh context reading only study.yaml, prepare.py, pipeline.py, the prepared artifact and the profile — program.md and every other study's files stayed closed. Rows 3–4 are mechanized: 9/9 checks passed: clean.

The most instructive row is target leakage. prepare.py's RAW_KEEP is an allowlist, not a denylist: it admits exactly 12 canonical raw columns and drops 46 hub columns — including the hub's derived Frequency column, which is the target in disguise. Go / no-go

Decision: GO-WITH-CAUTIONS. No BLOCKER open. Three WARNs carried forward as standing directives: (1) report the gap, never the levels; (2) derive interaction pairs from a train-fold surrogate only — the pairs are a caller-supplied argument, which is the one live lookahead surface no static check can catch; (3) never filter the 365× rate tail — exposure weighting already down-weights a one-day policy to 1/365 of a full-year policy.

One structural limitation the card flags for the findings: the prepared artifact has no time column, so a temporal split is impossible and the frozen random split is the only realizable design. Every conclusion here is an in-period statement about this portfolio, not a forward-in-time generalization.
