How to read this journey

Both tracks are registered: each run is a pre-registered cell that the notary measures, never a keep that beats an incumbent. So there is no climbing frontier here, and the trajectories below show cells in the order they ran, with the sealed confirmation cell marked separately. The table at the end of the section is generated from the run manifests.

Phase 1: the anchor (reproduction, development lane)

The first cell, E0001, reproduced Table 3 columns (1) and (2) and Table 1's sizes on the NSW and PSID-1 lanes. It missed two targets, the PSID-1 adjusted estimate and its standard error, and the notary refuted P1. That was foreseen at the METHOD gate, where reading Table 3 beside Table 2 showed that the NSW adjusted value matches one Table 2 column while the comparison-group values match another. The predictions were deliberately left as registered, and the reproduction cell gained never-counted diagnostic rows that show which regression each printed value corresponds to. The anchor's STOP rule fired only for an unexplained miss, so the study proceeded.

Phase 2: the estimators (att, PSID-1)

Four registered cells ran on PSID-1: IPW (E0002, P2), 1-NN matching (E0005, P4), AIPW (E0006, P3) and IPW without any 1974-earnings term (E0007, P5). Two run ids, E0003 and E0004, are driver-error crashes with no scientific content: a foreground tool timeout killed the run, and a re-launch on the restored cell was killed. They spent two of the four slots and forced a recorded budget re-record before the evidence it enabled. The notary then selected the sealed estimator by the registered rule, smallest absolute gap among P2 to P4, which chose AIPW. The selection was written down as a dated decision before any sealed access.

An operator error in the experimenter's checkout also removed filed evidence commits while E0005 was finishing and misnumbered the next cell. The lead killed that run before it printed a number, reset to the fully filed E0005, and the AIPW cell ran as E0006. Every leftover is preserved under incidents/ and the killed run is not evidence.

Phase 3: sealed confirmation (CPS-1)

Each track holds one sealed access, taken after a mandatory dry run. The sealed reproduction cell (E0008) and the sealed AIPW cell (E0009) are separate evidence from everything above. The first sealed att dry run hit the old 900-second limit on PSID-1 data under load (exit 124), so the budget was raised before the real run, which took far longer than the old limit. Without the dry run the track's only sealed access would most likely have been spent on a timeout. Both sealed runs are single draws; neither was re-executed, and the exact re-executions on record are of development cells.
