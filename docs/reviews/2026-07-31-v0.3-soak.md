## Friction log

(populated as encountered)

- **F1 (GRIND, headline)**: `klein new --task-type regression --metric
  val_poisson_deviance` is refused — the metric registry has no deviance metrics
  (Poisson/Gamma/Tweedie), so the flagship actuarial task (claim frequency) cannot
  be declared as what it is. The error message itself is good (lists the registry).
  Sanctioned workaround: `task_type: simulation` allows custom scalar metrics with
  an explicit direction — but that forces a real-data GLM-vs-GBDT study to label
  itself "simulation", and evaluate_scalar prints train/val rows as NA. Stage 2
  fix: add val_poisson_deviance / val_gamma_deviance / val_tweedie_deviance to the
  registry with a weighted evaluator (exposure weights), OR allow custom metrics
  for regression with explicit goal. The former also feeds the pricing-eval bridge.

- **F2 (GRIND)**: hand-running `train.py` to smoke it before the first `run-one`
  (with the KLEIN_* env vars faked, which the refusal message practically teaches
  you to do) APPENDED rows to `aux_metrics.tsv` — off-loop runs pollute the
  evidence sidecar and nothing warns. Had to truncate it by hand. Stage 2 fix:
  evaluate_* should skip sidecar/snapshot writes (or divert to a scratch path)
  when KLEIN_EXPERIMENT_ID is absent OR when an explicit KLEIN_SMOKE=1 is set,
  and the scaffold docs should name the sanctioned smoke-test path.

- **F3 (GRIND, compounds F1)**: `python -m kleinlib.leakage` FAILS on this study —
  it passes the contract's task_type through to `three_way_split`, which only
  accepts classification/regression. So the simulation escape-hatch (forced by the
  missing deviance metrics) also breaks the mechanized clean-room audit; checks
  3-4 had to be reproduced by hand. Confirms the F1 fix direction: put deviance
  metrics in the registry so real-data studies never need the simulation label;
  additionally leakage.py should map task_type simulation -> its declared split
  when the split kind is a real one (random/group/time), only skipping on kind none.
- W2: `kleinlib.profile_fallback` handled 678k rows cleanly — flagged IDpol as
  ID-like, produced the exact ClaimNb balance table the data card needs.

- **F4 (GRIND, protocol design)**: the noise-floor protocol ("vary only the seed")
  has no real-data recipe. Three defensible floors existed here and differ by 25x:
  fit-seed spread of the stochastic config (2x std = 0.0004), marginal dev-fold
  bootstrap SE (2x SE = 0.0108), and the PAIRED-difference bootstrap SE for model
  comparison (2x SE = 0.0018). The naive marginal floor would have called the
  study's headline GLM-to-GBDT gap (0.0101) borderline; the correct paired floor
  shows it at 11.3 SEs. Also the `noise_floor:` schema block can only hold the
  k-seed sweep's shape — the paired analysis lives in prose. Stage 2 fix:
  consult-protocol needs a real-data floor recipe (fit-seed AND paired-difference
  bootstrap for comparison studies; CRN language), and the block could carry an
  optional method: field. The measurement ITSELF was high value — this friction is
  about guidance, not machinery.

- **F5 (GRIND, driver UX)**: after E0004's discard, run-one restored train.py to
  the incumbent (correct!) — but my next edit assumed the discarded config was
  still in the worktree, the edit script failed halfway, and run-one happily ran
  an EMPTY candidate diff: E0005 is a bit-identical rerun of the incumbent
  (same metric to 6 decimals, honest discard). Two Stage-2 fixes: (a) run-one
  should WARN (or require --allow-rerun) when the candidate commit's train.py
  diff vs base is empty — an accidental rerun burns a phase slot silently;
  (b) the restore semantics deserve a louder post-run line ("train.py restored
  to E0003's config") so the driver's mental model resets. Silver lining: the
  accidental exact replication is itself evidence of end-to-end determinism.
- W3: disposition arithmetic held a razor-edge case honestly — E0002 kept by a
  margin of 0.000002 over minimum_delta; nobody would hand-wave that correctly.

- **F6 (PAPERCUT, protocol guidance)**: the sealed final test confirms the
  INCUMBENT'S level (dev 0.4447 -> test 0.4497, 0.65x fold SE — replicates), but
  for a comparison study the headline is the GAP, and one-access-per-track means
  the loser never gets a sealed number. Consult-protocol should say: when the
  research question is a comparison, model families as separate tracks (each
  with its own sealed access) OR label the gap exploratory-by-construction.
  Also: the sealed run's disposition prints as "discard" — correct mechanics
  (excluded from frontier) but jarring vocabulary for a confirmation run; a
  distinct "sealed" disposition label would read better.

- W4: the full newcomer lifecycle needed ZERO framework-code changes — every
  wall had a sanctioned (if sometimes awkward) path, every gate auto-commit
  fired, phase telemetry/summary/trajectory/tutorial all rendered on real data,
  and finalize passed lint-clean on floor-vocabulary findings.
- W5: knowledge/ priors did real work — 2 of 3 sourced priors held exactly;
  the glm-pricing card over-promised on shaping and now has a promotion-time
  caveat queued (the measurable-priors loop functioning as designed).

## Stage 2 priorities (ranked)

1. **Deviance metrics in the registry** (F1, unlocks F3's tooling and the
   Tweedie roadmap): add val_poisson_deviance / val_gamma_deviance /
   val_tweedie_deviance with exposure-weight support to kleinlib.eval; then
   frequency studies are task_type regression and everything downstream
   (leakage.py, evaluators, telemetry vocabulary) just works. Feeds the
   pricing-eval skill bridge naturally.
2. **Real-data noise-floor recipe in consult-protocol** (F4): fit-seed sweep
   AND paired-difference bootstrap for comparison studies; optional method:
   field in the noise_floor block; CRN language.
3. **Empty-diff guard + louder restore line in run-one** (F5): warn/require
   --allow-rerun on an empty candidate diff; print "train.py restored to
   <exp>'s config" after non-keeps.
4. **Smoke-run hygiene** (F2): evaluate_* skips sidecar writes without
   KLEIN_EXPERIMENT_ID (or under KLEIN_SMOKE=1); scaffold docs name the
   sanctioned smoke path.
5. **Comparison-study guidance** (F6): two-track pattern for sealing a gap;
   consider a distinct "sealed" disposition label for final-test rows.
6. Papercuts: gate auto-commit could sweep sweeps/; leakage.py should accept
   simulation-labeled studies with real split kinds.
